Entry for the [One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36) bounty on make.fun.

The program writes exactly one letter to `entry.txt`: **K**, for
"knackered" — the word that describes the sender's day. Flat-out worn
out, in the most vivid, funny and honest sense of the word.

## Run

```sh
python3 main.py
```

Writes the letter to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
